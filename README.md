# domain-services

A client site forked from the magentaweb design system in the mother `magentaweb-starter`, pinned at
the version in `package.json` -> `magentaweb` (forked at v5.2.0). The design system is inherited, not edited here: this
repo consumes the components and tokens and builds a real site on top.

- Run: `npm install` then `npm run dev`.
- Pin: see `"magentaweb"` in `package.json`.
- The full method and how to sync forward: `FORK_PROTOCOL.md` in the mother repo.

Read `HANDOFF.md` first, then `git log`. `SESSION_LOG.md` is the append-only narrative.
